# 📚 Book.Store

**Book.Store** is a web application for managing and selling books. It allows users to browse available books, search for specific titles, and purchase them easily.

## 🛠️ Features

- Display a list of available books  
- Search functionality  
- View detailed information about each book  
- Admin can add, update, or delete books  
- Shopping cart support  
- Simple and user-friendly UI

## 🔧 Technologies Used

- ASP.NET Core MVC  
- Entity Framework Core  
- SQL Server  
- Bootstrap / HTML / CSS  
- Git & GitHub
